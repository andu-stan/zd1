Connect

    

      
Plug the speaker into this computer with a USB cable and connect. The page talks to it over USB
         only: no network, no account.

      
This browser has no WebUSB: open the page in Chrome, Edge, Brave or Opera.

What is the speaker doing?

      

        Its light shows what it plays: red breathing as it starts, dim red in standby, white for the network, sky blue for USB
        
It runs our firmware: connect. Changes need a press of its ON/OFF key the first time (its light flashes
           purple): a web page can't press it.

      

      

        It still runs B&W's own software
        
B&W's firmware doesn't talk to this page and never shows up in the list. Start it in its bootloader
           instead: unplug its power, hold ON/OFF, plug the power in while holding it, then connect and pick the
           bootloader (03EB:2FF8). The page offers the install from there.

      

      

        It stopped during an update, or it doesn't start
        
It waits in its bootloader: connect and pick the bootloader. The page shows how far its firmware got and
           offers a repair or a backup this browser kept. If it isn't listed, hold ON/OFF while plugging its power in.

      

      

        It doesn't appear in the browser's list
        
    
          
  • Use a USB cable that carries data (some only charge), straight to the computer.
    • 
          
  • The browser: Chrome, Edge, Brave or Opera, on a desktop or on Android. Safari and Firefox have no WebUSB.
    • 
          
  • Windows can't open the speaker yet: its firmware lacks the descriptors Windows needs (macOS, Linux and Android work).
    • 
          
  • Linux: give your user the device with this rule, then plug the speaker in again:
            
    sudo tee /etc/udev/rules.d/70-zd1.rules <<'EOF'
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2fe0", TAG+="uaccess"
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2ff8", TAG+="uaccess"
EOF
sudo udevadm control --reload-rules

Firmware

    

      
Its firmware isn't running: the main board waits in its bootloader for firmware. It gets here when
         asked to (an install), when ON/OFF is held while it powers up, or when its firmware doesn't start.
