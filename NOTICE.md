# Third-party code and material

Our code is MIT (`LICENSE`). This file lists what in the repo, and in the images it builds, is someone else's, under
which license, and where its source is.

## In the repo

| What | Where | Whose, license |
|---|---|---|
| Advanced Software Framework (ASF 3.x): drivers, USB stack, startup code | `mcu/asf/`; `mcu/link_zd1.lds` is ASF's UC3A linker script, adapted | Microchip Technology; Microchip's ASF license (use with Microchip products only), in each file's header |
| UC3A device family pack (DFP 1.0): part headers | `mcu/dfp-include/` | Microchip Technology; Apache-2.0 |
| AAC tables | `module/codecs/aac/aac_tables.c` (generated by `module/codecs/aac/tools/gentables.py`) | the codebooks and band tables of ISO/IEC 14496-3 as FFmpeg's `libavcodec/aactab.c` (FFmpeg 8.1.3) transcribes them; LGPL-2.1-or-later. Built into `zd1-aac`, the Warp0 AAC image and the host check (`check/aaccheck.c`) |
| ALAC decoder for Warp0 | `module/warp0/fw/alac.c`, `alac.h` | a port of shairplay-rust's `codec/alac.rs` (LGPL-3.0-or-later), itself after David Hammerton's `alac.c`; LGPL-3.0-or-later. Built into the Warp0 crypto image (the `zd1-warp0` crate, so `zd1-airplay`) |
| AVR32 instruction encodings | `emu/renode/avr32/insn.decode`, and `Avr32Decoder.g.cs` generated from it | Florian Göhler and Johannes Willbold's QEMU AVR32 target (QEMU decodetree), with our fixes; LGPL-2.1-or-later |
| FLAC test stream | `module/codecs/flac/rust/tests/data/music.flac`, `music.raw` | 0.25 s of music encoded with libFLAC 1.5.0 (`flac -8`) and its `flac -d` output; the recording's origin is not recorded |
| B&W's DSP data | `mcu/src/dsp_data.c` | Bowers & Wilkins: the ADAU1445 program and parameters from the stock MCU firmware 2.04.05 |
| Vendor binaries | `blobs/` (provenance in `blobs/README.md`) | Bowers & Wilkins, BridgeCo and Atmel (the MCU firmware, the bootloaders, the module image); Nokia (the HD-1's Linux kernel, kernel modules and Wi-Fi firmware) |
| Reverse-engineering material | `re/` | derived from the vendor firmware above: decompiler exports, disassembly, strings, dumps |
| DM870 product information | `docs/hardware/ref/dm870db.pdf` | BridgeCo's 7-page "DM870 Networked Media Processor" product brief |
| SMPS schematics | `docs/hardware/img/smps-schematic.jpg`, `smps-primary.jpg` | hand-drawn tracings of B&W's SMPS70 V1.1 power supply; their source is not recorded |

## Linked into our programs

- **shairplay-rust** (LGPL-3.0-or-later), our fork https://github.com/pawlowskialex/shairplay-rust (branch
  `zeppelin`; upstream https://github.com/metaneutrons/shairplay-rust): linked statically into the module's `zd1`
  program (`zd1-airplay`) and into `ap2send` (a lab tool). The rest of `zd1`'s source is in
  this repo, so it can be rebuilt against a changed shairplay-rust (`Cargo.toml`'s pin, then `nix build .#os-image`).
- **librespot** and **libmdns** (MIT), our forks https://github.com/pawlowskialex/librespot and
  https://github.com/pawlowskialex/libmdns (branch `zeppelin`): in `zd1` (`zd1-spotify`). `module/os/forks.md` lists
  the changes.
- **priority-queue** (LGPL-3.0-or-later OR MPL-2.0, used under MPL-2.0; through librespot) and every other crate in
  `Cargo.lock`: their own licenses, MIT/Apache-2.0 and similar permissive ones apart from these two; source on
  crates.io.
